# 📚 Library Management System (MERN Stack)

A full-stack Library Management System built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).

This project includes complete admin and student workflows with authentication, borrow/return management, overdue fine calculation, dashboard analytics, Cloudinary image uploads, and responsive modern UI.

# ✨ Features

## 👨‍💼 Admin Features

- Admin Authentication
- Add / Edit / Delete Books
- Upload Book Cover Images
- Manage Borrow Requests
- Approve / Reject Requests
- Manage Return Requests
- Dashboard Analytics
- Dynamic Borrow Duration Per Book
- Library Shelf & Rack Management
- Soft Delete Support

---

## 👨‍🎓 Student Features

- Student Authentication
- Browse Available Books
- Search & Filter Books
- Request Books
- View Borrowed Books
- Request Return
- Overdue Tracking
- Fine Calculation
- Responsive Dashboard
